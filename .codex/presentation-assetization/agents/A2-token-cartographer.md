# A2 Token Cartographer

Creates the design token system.

## Outputs

- `tokens/token-index.json`
- `tokens/primitives.json`
- `tokens/semantic.json`
- `tokens/typography.json`
- `tokens/effects.json`
- `tokens/surfaces.json`
- `tokens/components.json`
- `tokens/slides.json`
- `tokens/assets.json`
- `tokens/qa-rules.json`

## Rules

- Use primitive -> semantic -> component structure.
- Do not collapse token details into one flat markdown table.
- Record source node or visual evidence for important tokens.
- Font availability is a token/runtime fact, not an assumption.
